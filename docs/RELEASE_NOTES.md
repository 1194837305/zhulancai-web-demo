# 前两年 Web Demo · 2026-11-03

校园日程、角色剧情、答辩比赛与配音的前两年试玩版本。

- 包含此版本的 614 条配音资源。
- 包含此前的雨声暂停保护、场景加载及引导输入保护修复。
- 正常第二年结算后进入试玩结束页。
- 推荐电脑端新版 Chrome / Edge；多线程 Web 版需要跨源隔离和 SharedArrayBuffer。
- 首次下载及画面准备可能较慢；手机兼容性和低配设备性能不作保证。

请下载附件 `Zhulancai-Web-Demo-20261103.zip`，完整解压后运行 `start-demo.cmd`，或使用 Python 启动本地服务。该包需 Python 3.10+，无需 Godot。

网页存档保存在浏览器网站本地数据中，不会自动跨设备同步。

本次为冻结版本的 GitHub 作品集整理，没有纳入后续本地游戏开发内容。
